# 兵員数の導入と再検証

**基本100人の編成、実際の人数による損耗・火力・維持費・補充・保存を実装した。** 承久の乱開始時の5試行では、幕府方の通常兵が189,991〜190,001人、朝廷の通常兵が23,000人となった。これは史料規模に合わせた招集が機能したという結果で、実兵数が歴史学的に確定したことや、全員が京都へ到達したことを意味しない。

実装のゲーム挙動は `ae7b987`。追加の人数・陣営観測コードを含む監査対象は `b178218` で、この間にゲームのルール変更はない。[人数の設計と出典](../../manpower.md)を参照。

## 実装した内容

- 新規の通常陸上部隊は100人。小さな初期部隊や戦役中の大部隊は、各部隊の定員を明示して扱う。
- 定員と質を分離。損耗によって現在人数と火力が減り、訓練では人数や損耗率が変わらない。訓練費は定員に比例する。
- 補充には自国拠点・待機・食糧・鉄が必要。維持費は兵員に連動し、戦役招集には消費可能な兵站備蓄を付ける。
- 英雄・労働者・船団を通常兵に重複加算しない。乗船中の兵は所属軍に一度だけ計上し、併合では人数・定員・損耗を維持する。
- 上部の兵数、選択部隊、F3の各家と陣営の表示を人数に変更。船は6人の船ではなく6部隊を輸送する船団として表示する。
- 保存形式を第3版へ更新し、第2版の保存も100人編成に移行して読み込む。既に通過した年表の招集は再実行しない。

史料規模として採用した一度限りの目標は、東国結集30,000人、承久の乱の幕府方190,000人・朝廷23,000人。実数の確定値ではなく、各家への拠点数による配分はゲーム上の整理である。初期の頼朝・北条・土肥合計300人対大庭3,000人も、石橋山の記述を初期編成に取り入れた基準であり、戦闘の日時と出陣者全員を強制再現してはいない。

## 本番AIでの観測

乱数 `1,42,2026,12345,8675309` の5通りで、1179年1月から1221年7月まで全勢力AIで実際に進めた。15観測点、40勢力・63英雄を記録。5試行とも終了まで完走し、46固定拠点を維持した。

| 乱数 | 1221年5月の幕府方兵員 | 朝廷兵員 | 全国の陸上部隊数 |
|---|---:|---:|---:|
| 1 | 190,000 | 23,000 | 269 |
| 42 | 190,001 | 23,000 | 232 |
| 2026 | 190,000 | 23,000 | 237 |
| 12345 | 190,000 | 23,000 | 244 |
| 8675309 | 189,991 | 23,000 | 244 |

人数と描画部隊数は別であり、数十万人を数十万の駒で描画していない。表は月境界を越えた本番ステップ後の値で、同じステップに起きた損耗・補充も含む。目標を上回る既存軍を切り捨てないため、人数が目標を超える場合もある。

全75観測点で、現在兵員が定員を超えないこと、滅亡勢力の通常兵が0であること、ゲームが出力した陣営人数と所属各家の兵員合計が一致することを照合した。[人数の推移](manpower.md)、[人数の機械可読記録](manpower.json)、[元CSV](raw/)を参照。全国の人数は全勢力の合計で、幕府軍一つの人数ではない。

### 勝敗の再現について

兵員規模を導入しても、1183年の都落ち・1185年の平家敗退・1189年の奥州藤原氏敗退を、それぞれの基準月に成立させる結果はいずれも0/5。今回も歴史的展開の全面的な合格とはしない。

1221年7月の平安京は、乱数2026で熊谷氏、8675309で北条氏が領有した。実装された陣営所属では両者とも幕府方なので、**現在の所属による幕府方の平安京領有は2/5**。

一方、初回から比較用に固定している所有者IDリストには熊谷氏が含まれず、[従来指標の表](measurements.md)は1/5と出力する。この分類差を成功率の改善として混ぜない。初回と同じ代理指標なら前版0/5から今回1/5、実装された陣営の所属まで考慮した今回の結果なら2/5である。どちらも、戦役全体の兵站・到着・勝敗の再現が完成したという意味ではない。
