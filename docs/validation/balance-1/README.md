# バランス調整：英雄の療養・攻城・兵站・AI

史実の月や勝敗の完全一致を合格条件にはせず、時代の流れ・勢力の特徴・操作する余地を保つ方針で調整した。同盟や離反の年表、英雄の死去時期、固定拠点、承久の乱前の朝廷保護は維持し、領有や勝敗を日付だけで上書きしていない。

ゲーム挙動の調整前は `cf6245f`。観測コードを追加した `35ee927` を比較の基準として測定し、調整後は `496cdbe` を測定した。

## 英雄は12秒かけて回復する

- 敗北後は所属勢力の既存拠点へ退避。HP20%から標準速度で12秒かけて全快し、それから行動へ復帰する。ゲーム速度や一時停止に従うゲーム内時間である。
- 療養中は地図の戦闘対象・行動・支援から外す。敵が同じ英雄を延々と攻撃し続ける状態を防ぎ、攻め手には拠点を狙う時間を残す。
- 英雄図鑑には残り秒数、選択欄には残り秒数とHPを表示する。全快後も通常の武器の攻撃間隔は適用する。
- 療養中のHP・残り時間を第3版の保存形式のまま保存できる。併合されても引き継ぎ、史実の死去時期が来れば療養中でも退場する。
- 通常兵を復活させる効果は追加していない。英雄本人の生存と兵員数は別に扱う。

## 大軍は強いが、城門への攻撃には時間を使う

野戦の火力・人数・耐久は人数制導入時のまま。通常100人の部隊や1,000人までの部隊も弱めず、建物への攻撃だけに攻城幅の制限を設けた。

百人組の数を`m`とすると、建物への攻撃に用いる量は`min(m, 10 + sqrt(max(m - 10, 0)))`。実際には残存HP比率も掛ける。これはゲーム上の攻城幅の調整値で、史料が示す城門の定員ではない。部隊を描画上まとめるほど野戦で不利になる調整は避けた。

平地・能力1・守備射撃あり・守備兵と英雄なしの首都に対する単独1万人の攻城は、中央値で**6.73秒から19.93秒**へ延び、5試行とも最終的には攻略できた。守備側が対応する時間を増やしつつ、大軍の有利は保っている。

## 補充・兵糧・AI

- 敵兵が12マス以内にいる間は通常兵の補充を止める。拠点近くで戦いながら損失を補い続ける状態を防ぐ。敵が去れば、従来どおり食糧と鉄を払って補充する。
- 初期の食糧は、その初期軍の維持費2年分を下限として補正。兵員の多い勢力が、開始直後から人数に見合わない200の固定備蓄しか持たない状態を緩和する。保存の読み込みで食糧を補充し直す処理ではない。
- 自由宣戦では対象一家だけでなく、その同盟勢力の戦力も考慮する。弱い一家を狙って大きな陣営へ無謀な戦争を始める行動を抑える。史実の年表による開戦はこの制限を受けない。
- 比企・畠山・和田との戦争が実際に始まった場合、古い奥州遠征などより優先する。承久の乱の朝廷との交戦は最優先。和平や既に滅亡した相手を無視して攻撃する処理ではない。

## 比較実測

前後で同じ乱数 `1,42,2026,12345,8675309` を使用。全期間AIでは1179年1月〜1221年7月を実際に進め、両版とも5試行が完走し、46拠点を維持した。

| 指標 | 調整前 | 調整後 |
|---|---:|---:|
| 1万人による単独攻城の中央値 | 6.73秒 | 19.93秒 |
| 上記の最終攻略 | 5/5 | 5/5 |
| 野戦6ケース×5乱数の結果 | 基準 | 時間・人数・勝敗すべて同じ |
| 1179年12月：食糧1未満の勢力の観測数 | 7/200 | 5/200 |
| 1221年7月：実際の陣営所属による幕府方の平安京領有 | 2/5 | 5/5 |
| 1183年8月：平家が六波羅を失う | 0/5 | 5/5 |

**食糧不足がすべて解消したわけではない。** 初期の大庭・木曽ではまだ一部の試行で食糧不足が観測される。表は観測時点の値であり、飢餓の継続時間や人数を示すものではない。

承久の乱開始時は、全5試行で幕府方190,000人・朝廷23,000人となり、史料規模として採用した招集目標は維持した。[調整後の人数推移](after/manpower.md)を参照。

野戦比較では100人の歩兵が、同人数の弓兵・騎馬武者との正面衝突に勝った。これらは自動追撃・正面戦のケースで、騎射の引き撃ちや移動速度を使う人間の操作は測定していない。1,000人1部隊と100人10部隊には包囲・位置・射線の差があり、同じ結果になるとは限らない。

平家・奥州藤原氏の敗退や比企・畠山・和田の政変は、まだ史実月どおりには決着していない。戦果の帰属も北条氏だけとは限らない。今回はそのズレを日付による強制処理では補わず、遊べる戦闘と兵站、時代の進行を優先する。

5試行は探索的な確認であり、全乱数の勝率や人間が操作した場合の楽しさ・難易度を推定する標本ではない。歴史的に不利な勢力にも同じ勝率を与える調整ではない。
