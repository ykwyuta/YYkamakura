# 兵員数の実測

本番挙動 `496cdbe`。記録した陣営IDと兵員を用いて集計し、所属規則を集計側で推測していない。

英雄・労働者・船団を通常兵に加算せず、乗船中の兵員は通常兵に含める。定員は満員時の人数、現在人数は損耗を反映した値。
