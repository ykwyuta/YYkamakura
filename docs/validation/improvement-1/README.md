# 第1回改善：共同出兵・遠征AI・戦役の時間

主要戦役が史実の時期に決着する段階にはまだ達していない。今回、共同出兵が機能し、木曽勢の敗退は以前より早まった。しかし京都攻略の成立は引き続き0/5であり、史実再現の合格とはしない。

## 実装した変更

- 各武家は拠点・兵・固有英雄を保ったまま、鎌倉方として対外戦と和平を共有する。陣営内の自由宣戦を止め、汎用AIによる無秩序な御家人同士の征服を抑える。
- 比企・畠山・和田はそれぞれの対立時期に共同陣営から外れる。和田合戦では三浦も幕府方として交戦する。
- 平家、木曽、奥州、承久の乱へと共通の遠征目標を切り替える。目標が生存し、実際に交戦中の場合だけ採用する。遠征は既存の経路探索・輸送・戦闘で実行する。
- 領内の少数の侵入者で遠征軍全体が引き返す指揮を変更。本拠近くの守備隊を最大約3分の1残し、残る兵は遠征を続ける。
- 西国追討期（1183年7月〜1185年3月）は暦を3倍、1189年7〜9月は6倍、1221年5月〜終了は24倍ゆっくり進める。戦闘速度や移動速度自体は変えない。
- 既に併合された家の政治イベントは元の家の記録として「未発生」にする。征服者への誤った政治権力の付与を止める。英雄・兵・資源の併合継承は維持する。

陣営は日付と各家の生存状態から導出するため、既存の保存形式を変更しない。加入時期を一括設定した家々や1205年以降の北条の指導権はゲーム上の整理であり、個別の臣従年月や幕府の制度全体を厳密に表したものではない。独立外交、忠誠度、御家人の離脱交渉などは未実装。

三浦の和田方から北条方への転換の史実比較には[神奈川県の資料](https://www.pref.kanagawa.jp/docs/d2t/kanko/p632084.html)を用いた。その他の比較資料は[初回報告](../README.md#史実の比較資料)に保存してある。

ゲーム挙動の対象は `aa911c5`。初回と同じ乱数 `1,42,2026,12345,8675309`、全勢力AI、1179年1月〜1221年7月、15観測点、46固定拠点・63英雄を用いた。結果や領地を日付で上書きする処理は追加していない。

共同交戦は `raw/seed-*-factions.csv` の1180年11月の交戦相手から確認した。木曽勢の敗退は早まったが、攻略者は源氏だけでなく畠山・足利・朝廷も含む。早期の決着だけで当事者まで合格したとは扱わない。最終時点の存続勢力数の多寡自体は、史実の近さの判定基準にしない。

**後退した項目もある。** 和田合戦は初回には史実時期の±1年以内の決着が4/5だったが、今回は0/5で、最後の拠点の喪失は1215.77〜1221.46年となった。遠征を優先する方針と幕府内部の政変を処理する方針の調整が必要であり、この版を史実再現が全面的に改善した版とは扱わない。

承久の乱に利用できる時間は約8秒から約192秒になった。初期地図の鎌倉〜平安京を騎馬武者が無抵抗・地形無視で移動する下限は約52秒。暦の配分上の障害は軽減したが、実際の経路・補給・輸送・攻城を含めた勝利は保証しない。今回も平安京の領有は動かなかった。

5試行すべてが完走し、46拠点と28件のイベント記録を維持した。通常テスト、陣営の保存再開・共同和平・歴史的開戦、少数の侵入者がいても遠征指示を出す回帰テストも実行した。[実測表](measurements.md)、[機械可読集計](summary.json)、[元データ](raw/)を参照。中間段階 `543e736` の共同出兵のみの測定も[別フォルダ](../prototype-mobilisation/)に保存した。

検証結果：通常Rustテスト37件（短い36件と全期間の`long_sim`を別実行）、5乱数の監査、移動時間監査、ブラウザ保護テスト9件、本番Wasmスモークが成功。Windows実行ファイルとWeb版のビルドも成功した。ログをこのフォルダに保存した。Windows版の実画面での再確認は今回の検証には含めていない。

## 次に解く問題

1. **進軍と攻城の停滞を分けて測る。** 地点別の兵数・命令・経路失敗・包囲中の損害・復活英雄への再照準を記録し、どこで主力が止まるかを特定する。今回の測定だけでは京都攻略失敗の主因を一つに断定できない。
2. **戦役の段階と兵站・輸送を実装する。** 東国集合、畿内進出、西国海戦、奥州追討、承久の乱の集結を区別する。目的地を選ぶことと、輸送・補給を備えて到達することを別々に検証する。
3. **幕府内政の政変を野戦と区別する。** 比企・畠山・和田は陣営の切替だけでは史実月に決着しない。政治的な動員・降伏・既存拠点の接収条件が必要。
4. **初期領有を見直す。** 1179年から頼朝が鎌倉を持つ先取りは今回未修正。既存拠点は維持し、当時の実効支配と臣従を資料で分けて整理する。
