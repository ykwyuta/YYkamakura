# 史実とゲームの採用値

1179年から承久3年7月までを扱う仮想戦記。史実の日付を軸とした同盟・離反・人物の死去と、プレイで変わる領有を組み合わせる。旧暦の月を年の12等分に対応させ、閏月と日単位は省略する。史実の戦いの勝敗による強制的な領有変更は行わない。

## シナリオの整理と未確定事項

- 全ての武家や荘園を網羅せず、奥州・東国・畿内・四国・九州の40勢力を代表として採用。朝廷と熊野水軍も勢力として扱う。
- 源氏・北条・三浦・和田などは、史実では主従・縁戚関係にあった家を別操作勢力に整理する。同盟は休戦として表現。共同指揮・婚姻・官職制度は実装しない。
- 「拠点」は館・国府・寺社周辺・荘園を含む広域の代表点。実測図ではない。祇園城・亥鼻・菅谷館など、後世に知られる史跡名も使う。1179年の建物の存在・当主の常住・正確な位置を全件確定したものではない。
- 源氏の鎌倉、平家の福原・屋島・彦島、奥州の多賀国府などは、既存拠点を全期間で固定するため、氏族に関連する支配・活動圏を初期領有として先取りする。初期領有は1179年の全国所領台帳の再現ではない。
- 密集する館は地形と2×2マスの当たり判定に合わせて付近にずらす。地名は元の家と元の地点で識別し、攻略後も維持する。
- 院など軍人でない人物の英雄ユニットは、勢力の指導力を表す。全人物が騎乗して戦ったと主張しない。一般兵と日本建築はYYMongoliaの生成画像を再利用する。英雄63人は新たに画像生成した固有画像を使う。いずれも個人の真の顔貌や個別の館の実測復元ではない。
- 頼朝1199年1月、清盛1181年2月、義仲1184年1月、秀衡1187年10月、広常1183年12月、比企能員1203年9月、畠山重忠1205年6月、和田義盛1213年5月、実朝1219年1月などを月単位で退場させる。併合されても退場時期は変わらない。
- 土肥実平は没年に諸説があり、1191年7月をシナリオ採用値とする。小山政光は1199年、湯浅宗重は1195年という採用値。那須与一・緒方惟義・原田種直・渋谷重国は生没年の確定が難しいため、シナリオ中は史実死去を断定した強制退場を設定しない。個別年表は今後の史料調査対象。
- 義経は1180年10月に登場し、1185年11月に朝廷側、1187年2月に奥州藤原氏側へ移る。独立した新勢力・新拠点は作らない。1189年4月に退場する。
- 先に併合された家のイベントは継承関係をたどって適用する。同じ継承勢力同士の戦争は起こさない。比企・畠山・和田の事件は、対象勢力が別勢力として存続すれば敵対を強制し、死去は領有とは別に適用する。自動的な内戦分裂は未実装。
- 朝廷の保護は1221年5月の開始時点まで。攻略・併合・全滅処理の各入口で保護を確認する。
- 勝利条件は1221年7月の支配拠点数。幕府方の勝利を強制するものではない。

## 流用元と検証範囲

YYMongoliaのローカルソース（確認時のmaster `1d0faefeacdfe0da0b4819b0b5b4fac6b3d02088`）から、描画・AI・資源経済・外交・海上輸送・入力・セーブ・ブラウザ回復処理と画像を流用。元作品のユーラシア年表・召喚ルール・テングリの終了条件はKamakuraでは使わない。元の国別画像や一部の内部型は共通資材として残す。`assets/period/generation.json` は流用画像の元生成記録で、史実の根拠ではない。

Rustテストは月単位の年表・英雄・併合・朝廷保護・終了・保存復元を確認する。全勢力AIの42年半の進行でも拠点数が46のまま終了することを確認。史実の領有結果・難易度・全勢力の勝率の校正を保証するものではない。


## 西国勢力と固有英雄の追加

中国地方の妹尾氏（妹尾荘・妹尾兼康）、阿波の田口氏（桜庭館・田口成良）、北部九州の山鹿氏（山鹿荘・山鹿秀遠）、秋月氏（秋月荘・秋月種雄）、阿蘇氏（阿蘇神社・阿蘇惟泰）、信濃の平賀氏（平賀館・平賀義信）を加え、40勢力46拠点とする。平家には清盛・知盛・重衡・重盛を同時に所属させ、宗盛が後に登場する。北条氏なども複数英雄を持ち、併合時も人数制限で英雄を削除しない。

妹尾兼康は1183年10月（閏月は省略）、平知盛は1185年3月、平重衡は1185年6月、平重盛は1179年8月を退場時期とする。平賀義信は1207年を採用値とし、田口成良・山鹿秀遠・秋月種雄・阿蘇惟泰は没年不詳として期間内の強制退場を設定しない。初期の当主・代表点の編成にはゲーム上の整理がある。

[長野県立歴史館の信濃史料索引](https://adeac.jp/npmh/top/topg/03003.html)には1183年10月の妹尾兼康討伐、[国立国会図書館レファレンス協同DB](https://crd.ndl.go.jp/reference/entry/index.php?fi=4_%E4%BA%BA%E7%89%A9+8_33&id=1000151120&ldtl=1&page=ref_view&type=reference)には田口成良の生没年や屋島での活動の不確実性、[遠賀町誌](https://www.town.onga.lg.jp/site/choshi/26901.html)には平家方の北部九州勢力の記載がある。

英雄の原画・プロンプト・ID対応は `assets/heroes/` に保存する。7枚の3×3スプライトシートから63人分を切り出し、元のRGBAを保持したPNGと、描画用の乗算済みBGRAを作る。同一画像の使い回しがないこと・透明背景・全英雄IDの対応を検証する。


## 女性の英雄・支援者

北条政子（北条氏）、静御前（源氏・1186年3月登場）、巴御前（木曽源氏）、丹後局（朝廷）、比企尼（比企氏）、二位尼・建礼門院徳子（平家）、牧の方・阿波局（北条氏）を追加。合計63人とする。

巴は軍記の女武者像を採用した戦闘英雄。それ以外は攻撃力0の政務・芸能支援ユニットとし、所属する勢力の生産・軍の攻撃・維持費・施設防御などを補正する。これらの数値効果はゲーム上の抽象化で、舞に超自然的な力があった、非戦闘者が実際に軍を率いて攻撃したという主張ではない。AIは非戦闘支援者を労働部隊として伐採・建設へ動員しない。

政子は1225年7月、二位尼は1185年3月、建礼門院は1213年12月、丹後局は1216年、阿波局は1227年11月を採用値とする。静・巴・比企尼・牧の方の生没年や消息には不確実性があるため、期間中の死亡を断定した強制退場を設けない。白い法衣などの画像は人物の代表的な後年の姿を含み、毎年の年齢や出家前後の衣装を切り替えたものではない。

[鎌倉市の政子展案内](https://www.city.kamakura.kanagawa.jp/rekibun/documents/hojomasakotirasi.pdf)を政子の政治的な位置付け、[鎌倉市掲載のフェリス女学院資料](https://www.city.kamakura.kanagawa.jp/taiga/documents/ferisgaido.pdf)を静の生没年未詳・1186年の舞・政子の取りなしの根拠として参照。[久喜市の静御前資料](https://www.city.kuki.lg.jp/miryoku/rekishi_bunkazai/kankobutsu/jinbutsu_booklet/booklet02.files/shizukagozen_no_densho.pdf)も伝承を検討する資料とする。政子の1221年の訴えと静の1186年4月の舞を年表へ加え、全28件とする。
