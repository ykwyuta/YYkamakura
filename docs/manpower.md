# 兵員・編成・史料規模

通常の新規陸上部隊は**100人編成**。部隊ごとに定員を保存し、現在の兵員は定員と損耗率から算出する。大軍は複数の百人組を一つの駒にまとめ、選択欄に実際の定員と現在人数を表示する。描画する駒の数と兵員数を混同しない。

## 数値の根拠と採用範囲

| 時期 | ゲームで採用する目標 | 根拠・性格 |
|---|---|---|
| 挙兵前夜〜石橋山 | 頼朝・北条・土肥の初期通常兵を合計300人、大庭を3,000人 | [小田原市の石橋山古戦場](https://www.city.odawara.kanagawa.jp/kanko/corridor/historic_battlefield/p10043.html)が紹介する約300騎対約3,000騎を基準とした開幕編成 |
| 1180年10月の東国結集 | 存続する鎌倉方の合計30,000人を目標に一度招集 | [福井市の解説](https://www.city.fukui.lg.jp/kankou/kankou/jouhou/introduce_shimizu-yuhki.html)にある、房総結集後の三万余の軍勢を規模の基準に採用 |
| 1221年5月の承久の乱 | 存続する幕府方190,000人、朝廷23,000人を目標に一度招集 | [鎌倉市の学芸員解説](https://www.city.kamakura.kanagawa.jp/kouhou/kamakura/21/t210901-6-7.html)に幕府方十九万の記述。[日本大百科全書等の解説](https://japanknowledge.com/introduction/keyword.html?i=2097)では幕府方十九万余騎・京方二万数千とされる。23,000は「二万数千」のゲーム上の採用値 |

**これらは実数が確定した歴史人口ではない。** 史料の「騎」には家の子・郎党等の数え方の問題があり、そのまま現代の人員統計とは扱えない。とくに承久の乱の十九万については、[早稲田大学の講座解説](https://www1.ex-waseda.jp/wp-content/uploads/19_waseda_hatchobori_nakano_spring.pdf)でも実数とみなすことへの疑問が示されている。本作は記載された規模を「兵員相当数」の設定として採用し、研究上確定した実兵数を再現したとは主張しない。全国各家の兵力が史料で個別に判明しているわけでもない。

招集の目標は**出陣して勝利した人数ではなく、既存拠点で編成する軍勢の規模**。実際に戦場へ到達する人数は、戦死・離脱・補給・経路・輸送・プレイヤーの操作で変わる。石橋山の敗走そのものや、その日時点の出陣兵力を強制する処理は今回追加していない。

## 開始時の配分

1179年の開始時に、通常兵の定員を次のように割り当てる。石橋山の規模を初期状態へ先取りした設計であり、1179年の全国軍籍を復元した表ではない。

| 勢力 | 初期通常兵 | 扱い |
|---|---:|---|
| 頼朝・北条・土肥 | 各100人 | 合計300人。各家の3駒に33・33・34人として配分 |
| 大庭 | 3,000人 | 石橋山の相対規模の基準 |
| 平家・奥州藤原 | 各6,000人 | 複数拠点の有力勢力としてのゲーム上の配分。史料の実数ではない |
| 木曽・甲斐源氏・朝廷 | 各1,000人 | ゲーム上の配分 |
| その他の各家 | 各300人 | 100人編成を3部隊。個別の史料値ではない |

開始時の通常兵は全国合計27,600人。これに初期49人の英雄を別枠で表示する。英雄・労働者・船団を通常兵に重複加算しない。

## 戦闘・補充・兵站

- 兵員の損耗はHP比率から算出し、野戦の攻撃力も残存兵員に比例して低下する。定員1,000人の部隊が半壊すれば約500人で、同じ質の満員部隊の約半分の攻撃力となる。建物への攻撃は、大軍全員が同時に門を攻撃できないものとして増加幅を抑える。
- 訓練で上がるのは質と耐久。定員・兵員は増えず、損耗も消えない。訓練費は編制定員に比例し、大軍を100人分の費用で一括強化することはできない。
- 通常兵の補充は自国の既存拠点から12マス以内で待機中に行う。食糧と鉄を消費し、無資源・移動中・乗船中・敵地・敵兵が12マス以内にいる間は補充しない。村や街を新設する必要はない。
- 補充速度は定員の毎秒1%まで、1人あたり食糧0.05・鉄0.01。維持費は毎秒`0.07 × 質 × 現在兵員 / 100`。これはゲーム内資源単位であり、実際の石高や消費重量ではない。
- 年表の招集では軍勢とともに食糧・装備を用意する。新規招集1人あたり食糧0.25・鉄0.04の戦役用備蓄を追加し、その後は通常の維持費・補充費で消費する。備蓄は無限ではない。
- 初期兵や戦役招集の大きな部隊を労働者へ転換すると、その部隊を解兵する。再度兵へ転換する場合は100人編成となり、元の大軍は復活しない。

HPは戦死者だけでなく負傷・離脱・戦闘不能をまとめた損耗の抽象化。人口台帳や兵の出身村・個別の帰農先は実装していない。

## 招集と所属

年表の招集は一度だけ実行し、同陣営の存続する武家へ、その時点で保有する拠点数に応じて配分する。史料が各家の内訳まで示すわけではないため、この配分方法はゲーム上の整理である。

招集は目標に足りない人数を補う処理。プレイヤーが既に多くの兵を持っていれば削減しないので、実際の合計は目標を超える場合がある。元の損耗を一括で消すこともない。既に滅亡した勢力は再建せず、既存拠点がない勢力や招集主体が滅亡している場合には予定の規模を保証しない。

全拠点を奪われた勢力の兵は、定員・残存兵員・質を保ったまま攻略者に移る。英雄は敗北後に拠点へ退避し、標準速度で12秒かけてHP20%から全快まで療養する。この間は行動・支援・敵の攻撃対象から外れ、英雄図鑑と選択欄に残り時間を表示する。復帰するのは本人だけで、通常兵が増える効果はない。療養中も併合と史実の死去時期を適用し、残り時間とHPは保存する。

軍船の駒は**船団**として扱い、最大6部隊の編成枠を輸送する。1隻に6人という意味ではなく、乗船中の人数も所属軍へ一度だけ計上する。個々の実船数や乗組員数を算出する海運モデルではない。

## 表示と保存

- 上部の兵アイコンは通常兵の現在人数を表示。ツールチップに定員・編成数・編成枠上限・船団・英雄・同陣営の合計を表示する。
- 単体・複数部隊の選択欄は人数を表示。HPを「兵力」と呼んでいた表示は耐久へ改めた。
- F3の歴史画面には自国と陣営の人数、各家の人数を表示。年表の招集説明には史料規模を採用した設定であることを明記する。
- 保存形式は第3版。各部隊の定員を保存し、損耗と招集済みの年表位置も維持する。
- 第2版の既存保存も読み込む。旧通常部隊は100人編成として損耗率を引き継ぐ。既に通過した年表の招集を遡って再実行しない。

数値・保存互換・損耗・補充・乗船・英雄復活・併合・招集をテストし、本番AI進行の観測では実際の兵員と定員をCSVへ出力する。[今回の実測記録](validation/manpower-1/README.md)を参照。
